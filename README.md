# regimeswitching (view as [web page](https://regimeswitching.org))

Pricing libraries for models whose parameters switch with a hidden Markov regime, priced by the fast-switching
expansion with a referee for every number. The site: a landing page, the languages page, and the Python API
documentation of [regimelib](https://github.com/microprediction/regimelib) under `docs/python/`, built from that
repository's `docs/` with Sphinx:

    python -m sphinx -b html ../regimelib/docs docs/python && rm docs/python/CNAME

GitHub Pages serves `docs/` on main. The mathematics is at
[homogenization.microprediction.org](https://homogenization.microprediction.org).
